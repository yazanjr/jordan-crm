# Frontend Design Skill Overview

This skill enables creation of distinctive, production-grade web interfaces that prioritize genuine design intentionality over generic aesthetics.

## Core Approach

The framework emphasizes understanding context before coding—identifying purpose, audience, tone, and technical constraints. Designers should commit to a "BOLD aesthetic direction" whether that's minimalism, maximalism, or any other cohesive vision.

## Key Aesthetic Priorities

**Typography**: Choose fonts that are beautiful, unique, and interesting. Avoid generic fonts like Arial and Inter in favor of distinctive, characterful selections paired thoughtfully.

**Visual Composition**: The guidance encourages unexpected layouts, asymmetry, overlap, and atmospheric details rather than flat solid backgrounds. Motion design should feature high-impact moments like staggered page-load reveals.

**Avoiding Clichés**: The skill explicitly warns against overused patterns—purple gradients, predictable layouts, common font families, and "cookie-cutter design that lacks context-specific character."

## Implementation Philosophy

Code complexity should match aesthetic ambition: maximalist designs warrant elaborate implementations with extensive effects, while refined minimalist work demands precision and restraint. The underlying principle is that intentional, well-executed vision—whether bold or restrained—creates memorable interfaces that feel genuinely designed rather than algorithmically generated.
